# Glowtune 0.5.0

> **Early build.** Glowtune is new and still has bugs. If something breaks, please tell us (see *Found a bug?* below).

> **🔊 Volume tip.** Turn the volume **all the way up inside Spotify, YouTube Music or SoundCloud**, then set how loud you want it with **Glowtune's** volume. With Automix, Crossfade or the Equalizer on, the two aren't linked.

## What's new

**Lyrics that stay in time.**
- Glowtune now lines up the lyrics by itself for songs in **Spotify, Chrome, Edge, Brave, Firefox** and other apps, not only inside Glowtune. It listens for where the singer comes in, then moves the lyrics to match.
- Still off? **Ctrl+Alt+,** and **Ctrl+Alt+.** move them later or earlier from anywhere, even in a game. **Ctrl+Alt+T** syncs them back to 0 s.
- The same **Later / Sync / Earlier** are in the desktop scene's menu, and in **Settings › Lyrics**, where you can also type the exact timing.

**Lyrics that tell you why they're hidden.** When the floating lyrics hide on purpose (your music app fills the screen, or the song only has unsynced lyrics), Glowtune says so once, and **Settings › Lyrics** shows why.

**All the lyrics settings in one place.** Animation, position, size and font moved from the theme editor to **Settings › Lyrics**. Each one can follow the theme.

**Settings search that finds the setting.** Type what you're after, typos and all ("revers moton" finds Reverse motion), and it jumps straight to it. **Ctrl+F** to search.

**Open Settings faster.** Press **Ctrl+Alt+O**, or double-click the tray icon.

**Send us feedback from the app.** **Settings › Feedback**: tell us about a bug, an idea, or what you think. No account needed.

**What's new, right in the app.** After an update you'll see a small card like this one.

## Fixes

- A theme's fonts no longer change the Settings window: the lyrics font is only for lyrics, the interface font only for the player.
- Automatic lyrics timing now works with only the Equalizer on, too.

## Known issues

- **Apple Music** is barely tested.
- **Automatic lyrics timing** needs to hear the song start: if you skip into the middle of a song, use Later, Earlier or Sync.
- **The service's own volume slider and Glowtune's volume aren't linked** while Automix, Crossfade or the Equalizer is on.
- **Switching your audio output device** while Sound effects are on can leave the effects off for up to a minute.
- **The Clear player** catches clicks across its whole area, including the see-through parts.
- The installer isn't code-signed yet, so Windows SmartScreen shows a warning. Choose *More info › Run anyway*.
